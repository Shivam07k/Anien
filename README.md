# Birthday Card for Himanshi Jaglan (Anien)

A simple static birthday card webpage made with love.

**By : Lalu Deshwal & Muskan Jaglan**

## Features

- Animated typewriter birthday message
- Floating photo bubbles (click one to see it full size)
- Heart + confetti canvas animation
- Live birthday countdown and age
- Background song (autoplays on load)

Open `index.html` in a browser to view it.
